ATS · Authorization & Shape Constraints

URL layout: / (/index.html) is the public home (open roles + apply links); /apply.html is the public application form; /roles.html is the public composed roles feed; the private hiring dashboard lives at /admin/ (/admin/index.html).

/admin/index.html is fully private: no anonymous GET rule exists, so with the host in default-get-authz-mode: deny every anonymous read (whole-doc and selector-scoped) is refused. Only members of the admins group (see Groups below) can read it. Writes are gated to the admins group, except the single public POST #candidates-body window that lets apply.html submit applications.

Why roles live on a separate page: this platform treats any public selector-scoped GET allow rule as opening every selector of that resource for anonymous reads (explicit deny rules do not override it). So /admin/index.html cannot hold both private candidate data and a public roles window. Instead, /roles.html is a fully-public page that <p:include>s #roles-body from the private /admin/index.html via elevated server-side composition. The home page (/) and apply.html read roles from /roles.html; candidate/interview/activity data is never exposed.

Groups

Shape Constraints

Candidate row #candidates-body tr[itemtype="https://pagelove.org/Candidate"] :has([itemprop=id]) :has([itemprop=name]) :has([itemprop=roleId]) :has([itemprop=stage]) :has([itemprop=owner]) :has([itemprop=firstContact])
Candidates table — CLOSED (untrusted public write path)

Fires when the anonymous POST #candidates-body target is hit. Being closed (it declares permits), it rejects any element or attribute not listed below with 422 — so no <script>, <img onerror>, style/on* handlers, or other markup can be stored via the public form. Permits are the union of every element/attribute used by real candidate rows (stored data, apply.html, and the admin renderer). Each is tied to a specific element so a bare-attribute permit can't let a foreign tag slip through.

#candidates-body tr[id][itemscope][itemtype] td td[class] td[hidden] td[itemprop] div[class] div[itemprop] span[class] span[itemprop] span[data-stage] span[data-priority] a[class] a[href] a[itemprop] time[class] time[datetime] time[itemprop]
Role row #roles-body tr[itemtype="https://pagelove.org/Role"] :has([itemprop=id]) :has([itemprop=title]) :has([itemprop=hiringManager]) :has([itemprop=employmentType]) :has([itemprop=status])
Interview row #interviews-body tr[itemtype="https://pagelove.org/Interview"] :has([itemprop=id]) :has([itemprop=candidateId]) :has([itemprop=type]) :has([itemprop=date])
