ATS Starter

An applicant tracking system template built on Pagelove. One HTML file per screen, microdata as the data store, no database, no build step.

Try the internal ATS → See the public careers page

Both are pre-populated with fictional data (Ada Lovelace, Grace Hopper …). Click around freely.

This is a public demo. The admin at /admin/ is open to anyone who has the URL. When you fork this for your own hiring, add OAuth and lock /admin/* to your team's group. Rules scaffolding is already in /admin/auth.html — activate it by adding your emails and enabling default-get-authz-mode: deny on your host.

What's in the box

  • /index.html — public careers page (candidates land here)
  • /apply.html — public application form
  • /roles.html — public read-only roles feed (auto-composed from admin)
  • /roles/:role_name/ — example: parameterised route, one file serving every role's public page
  • /admin/ — the ATS itself: kanban, candidates CRUD, activity log, email templates, CSV-friendly microdata
  • /outbox/index.html — Pagelove Trigger + HttpRequest that relays outbound email to Postmark server-side (drop your token in to enable)

Make it yours

  1. Fork this project in the Pagelove console
  2. Search-and-replace Example Co across the files with your brand
  3. Open the admin, delete the seeded fake roles + candidates, add your own
  4. To enable email sending: paste your Postmark Server API Token into /outbox/index.html (look for the empty <meta itemprop="value" content="">)
  5. To lock down the admin: activate the auth rules in /admin/auth.html and set your host's default GET auth mode to deny

The pipeline stages

Candidates move through: Sourced → Applied → Interview 1 → Interview 2 → Interview 3 → Offer → Hired, with terminal states Rejected, Withdrew, Duplicate. Change these in the admin's STAGES constant.
